문제 : 직접입력(custom) 옵션 선택 후 다른 옵션 선택을 하면 
         로직이 꼬인듯이 입력한 값이 updateMembershipContainer 함수에서 반영되지 않음
        다른 옵션 선택 시에도 입력값 초기화가 제대로 이루어지지 않아 동작에 혼란이 발생.

문제 원인 : 1. 다른 옵션 선택 시 기존 입력 필드 제거해야하는 로직 필요 
              2. change 이벤트에서 custom 옵션에 따른 입력값 생성과 초기화를 적절히 처리하지 않아 이벤트가 중복 호출되거나 불필요한 입력 필드가 남음.
              3. 동일한 옵션을 여러 번 선택하거나, 다른 옵션 선택 후 이전 상태가 초기화되지 않아 상태가 꼬이는 현상 발생.

원인 정리: 직접입력은 별개의 input이라 셀렉옵션과는 초기화를 하는 별도의 로직을 추가했어야했음

방법 : 1. removeCustomInput 함수를 추가하여 기존 custom 입력 필드를 제거하는 로직을 추가
        2. 업데이트함수 호출전에 입력 필드 초기화를 먼저 처리

해결 : 잘못된 입력값이나 잔여 입력 필드가 남지 않고 깔끔히 초기화.
