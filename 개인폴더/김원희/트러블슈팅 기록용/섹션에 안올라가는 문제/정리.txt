발표 포인트

서버에서 @SessionAttribute 저장된 데이터를 프론트엔드에 전달할 때 발생한 데이터 전달 문제

기존에 써왔던 코드이며 코드상에 문제가 없어보임에도 섹션에 실려있는 정보를 읽어오지 못함
스프링쪽 콘솔에서는 섹션에 추가 되어있다고 나오나 개발자도구에선 찾지못함

해결 방법

서버에서 데이터를 <meta> 태그에 삽입하여 JavaScript에서 데이터를 간편하게 가져올 수 있도록 수정.
간결하고 직관적인 데이터 전달 방식.

★서버와 프론트엔드 간 데이터 연계를 보장★

<meta> 태그는 브라우저에 기본적으로 지원되며, 추가적인 설정 없이 바로 사용 가능.

결론
이 방식은 세션 데이터 접근 문제를 해결하는 동시에, JavaScript에서 데이터를 보다 안정적으로 처리할 수 있게 합니다.
